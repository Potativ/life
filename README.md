# LIFE

Персональный трекер целей и времени. Статический сайт для GitHub Pages.

## Что уже работает
- Добавление и выполнение целей; категория указывается в скобках: `Пробежать 3 км (Физическое развитие)`.
- XP и уровни, серия активных дней, статистика категорий.
- Таймер работы, отдыха и развлечений.
- Заметки дня.
- Локальное сохранение в браузере.
- Подключение к GitHub Contents API для общей синхронизации между устройствами.

## Публикация
1. Создай **публичный** GitHub-репозиторий, например `life`.
2. Загрузи `index.html`, `data.json` и `README.md` в корень репозитория.
3. В репозитории открой **Settings → Pages**.
4. В разделе Build and deployment выбери **Deploy from a branch**, ветку `main`, папку `/ (root)`, сохрани.
5. Открой адрес GitHub Pages.

## Подключение синхронизации
1. Создай отдельный репозиторий `life-data` для данных. Если хочешь, чтобы цели и журнал не были публичны, сделай его **private**.
2. Внутри него создай `data.json` с содержимым `{}`.
3. В GitHub открой Settings → Developer settings → Personal access tokens → Fine-grained tokens.
4. Создай токен, ограничь его только репозиторием `life-data` и дай **Contents: Read and write**.
5. На сайте LIFE нажми «Настройки», введи свой GitHub username, `life-data` и токен. Нажми «Подключить / загрузить».
6. Повтори ввод этих настроек на втором устройстве. Токен хранится локально в каждом браузере и не включён в файлы сайта.

## Важно о приватности и безопасности
- Репозиторий сайта для бесплатного GitHub Pages должен быть публичным.
- Данные можно держать в отдельном приватном репозитории `life-data`; сайт будет читать/обновлять его через API с введённым токеном.
- Токен доступен браузеру, в котором ты его ввёл. Не вводи его на чужих устройствах, используй отдельный токен с доступом только к одному репозиторию и отзывай его, если устройство потеряно.
- Не публикуй токен в коде, `index.html`, `data.json` или README.
- Эта версия синхронизирует данные при подключении и после сохранения заметки/завершения таймера. После добавления/изменения цели, завершения таймера и сохранения заметки выполняется попытка синхронизации. Одновременное редактирование на двух устройствах может привести к конфликту версий.

## Ограничение первой версии
Пока это стартовая версия: интерфейс и основные механики готовы, но импорт больших списков задач, редактирование целей, календарь и полноценная автоматическая синхронизация после каждого действия — следующие улучшения.
